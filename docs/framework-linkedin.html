What is OKF?

Open Knowledge Format (OKF v0.2) is an open, human- and agent-friendly format for representing knowledge using markdown files with YAML frontmatter.

  • Readable by humans without tooling
  • Parseable by agents without SDKs
  • Diffable in version control
  • Portable across tools and orgs
✔
Why OKF with Playwright?

AI agents can read OKF knowledge to understand Salesforce objects and generate better tests.

  • Agents understand SF object schemas
  • Selectors are version-controlled
  • Patterns are reusable across tests
  • Knowledge accumulates over time
